# Style Guide

Единые правила стилизации приложения. Источник истины — макет в Figma; здесь зафиксировано то, что уже перенесено в код (`lib/common/theme.dart`), чтобы не расходиться при добавлении новых экранов.

## Цвета

| Назначение | Hex | Где используется |
|---|---|---|
| Текст (основной и вторичный) | `#423A2A` | Весь текст в приложении |
| Акцент / кнопки | `#C86848` | Основные кнопки, активный элемент навигации |
| Фон экрана | `#E9E0C9` | `Scaffold` background |
| Карточки | `#E9E0C9` | Тот же тон, что и фон — отделяются тенью, а не цветом |
| Диалоги/попапы (elevated) | `#F4F1E8` | Диалоги, bottom sheets — сознательно светлее фона, чтобы "выступать" над затемнённым экраном, а не сливаться с ним |
| Выпадающие меню (над страницей) | `#ECE5D1` | `AppSelectField`, `PopupMenuButton` (селект категории, выбор единиц веса) — эти всплывают без затемнения фона, поэтому цвет диалогов на них выглядел белым пятном; выбран более тёплый, ближе к цвету карточек |
| Выпадающие меню (поверх модалки) | `#F3F1EB` | `AppSelectField(menuColor: ...)` — когда меню открывается поверх уже приподнятой поверхности (например, «Родительская категория» внутри шторки создания категории), тёплый цвет выше сливается с фоном шторки; здесь нужен более светлый, серо-белый тон |
| Выделение (highlight) в меню | `#DCD3C0` (`trackBackground`) | Подсветка текущего выбранного значения в `PopupMenuButton` — по умолчанию Material красит её серым, здесь используется тот же тёплый тон, что и у полосы прогресса |
| Food | `#C96E4F` | Иконки/точки/сегменты категории Food |
| Gear (основной) | `#61795C` | Иконки/точки/сегменты категории Gear |
| Gear (светлый) | `#8BA078` | Подложки под иконками Gear (полупрозрачно) |
| Water | `#88A29E` | Иконки/точки/сегменты категории Water |
| Превышение веса | `#C62828` | Число общего веса, когда рюкзак перегружен |

Светлые подложки под иконки категорий — не эти цвета впрямую, а с прозрачностью (см. `lightColorForPackType` в коде): Food 18%, Gear 35%, Water 25% — подобрано на глаз под яркость каждого тона, при желании можно поправить.

## Шрифты

- **Lora, Medium** — только для крупной акцентной цифры общего веса на дашборде (`weightDisplayStyle`). Больше нигде не используется — это единственный акцентный элемент.
- **Inter, Regular** — весь обычный текст (названия вещей, подписи).
- **Inter, Medium** — заголовки, названия категорий, кнопки, элементы навигации.

Оба шрифта подключены через пакет `google_fonts`, отдельно скачивать/класть файлы шрифтов в проект не нужно.

## Форма и глубина

- Радиус скругления карточек: `14px`
- Радиус скругления бейджей-иконок: `9px`
- Тень карточек: мягкая, `blurRadius: 12`, смещение `(0, 4)`, цвет — основной текстовый цвет с прозрачностью 8% (`AppColors.cardShadow`). Не используем цветной фон, чтобы отделить карточку от экрана — только тень.

## Поля форм (`lib/common/input_decoration.dart`)

- Подписи полей — **всегда** обычный `Text` (виджет `FieldLabel`) над полем, **не** плавающий `labelText` внутри рамки. Так рядом с подписью можно свободно добавить что угодно (иконку-подсказку, значок обязательности) без борьбы с `InputDecoration`.
- Текстовые поля — только рамка (`appFieldDecoration()`), без заливки, тонкая полупрозрачная обводка (`AppColors.textPrimary` 20%), акцентная при фокусе. Обёрнуты в `SizedBox(height: kFieldHeight)`.
- Все выборы из списка — виджет `AppSelectField<T>` (свой, не Flutter'овский `DropdownButtonFormField`/`DropdownMenu` — у обоих были баги с позиционированием/высотой меню, которые не удалось до конца поправить через стили). `AppSelectField` выглядит как обычное поле и открывает список меню, привязанное прямо под полем (`showMenu`), поэтому гарантированно той же высоты и без "прыжков"/модалки поверх модалки.
- `AppSelectField(pinSelectedFirst: true)` — выбранный вариант всегда открывается первым в списке. Только для коротких плоских списков без смысловой иерархии (например, «Состояние»); для дерева категорий не используем — там порядок = вложенность.

## Общие принципы

1. **Один текстовый цвет на всё** (`#423A2A`) — разделение по важности идёт через шрифт (Lora/Inter, Regular/Medium) и размер, а не через дополнительные оттенки серого.
2. **Цвет = принадлежность к разделу** (Food/Gear/Water) — используется последовательно везде: точки в легенде, сегменты полосы веса, иконки категорий, подложки под ними.
3. **Не изобретаем новых цветов на лету** — если для новой фичи нужен ещё один акцент, сначала сверяемся с этим файлом/макетом, а не подбираем "на глаз" в коде.
